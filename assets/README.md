# Sivuston kuvat

Kuvat ovat Finnish Garage Simulator -projektin omia kehitysrendereitä. Ne eivät esitä valmista peliä eikä niitä ole otettu muista peleistä.

- prototype-car.png ja og-image.png: Screenshots/0.6/car.png (1600×900).
- prototype-work.png: Screenshots/0.7/wood-split.png (1280×720).
- prototype-garage.png: TestResults/PlayerSmoke09Verified/modular-hood-installed.png (1280×720), 0.9-kehitysbuild.

Pelin maastomateriaalissa on Poly Havenin Forest Ground 04 (CC0): https://polyhaven.com/a/forest_ground_04 ja https://polyhaven.com/license. Kuvissa olevat automallit ja kehitysgeometria ovat projektin omia.

Favicon ja sivuston typografinen tunnus ovat tätä sivustoa varten kirjoitettuja SVG-/HTML-elementtejä. Sivusto ei väitä tunnusta rekisteröidyksi tavaramerkiksi.
